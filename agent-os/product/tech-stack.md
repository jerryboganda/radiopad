# Tech Stack

## Frontend

- Next.js 16 App Router
- React 18 and TypeScript
- Build-time Tailwind CSS 3
- Static export for Tauri and Capacitor
- RC token system with light and deep-navy dark themes

## Backend

- ASP.NET Core 8 Web API
- C# with nullable reference types
- EF Core
- Layered Domain, Application, Validation, Infrastructure, and Api projects

## Database

- SQLite for development and tests
- PostgreSQL for production
- Append-only, integrity-chained audit events

## Other

- Tauri 2 Windows desktop (`.msi`)
- Capacitor 6 Android and iOS companion
- .NET 8 global CLI tool
- GitHub Actions for full builds, tests, lint/typecheck, packaging, and releases
- Provider adapters behind the application AI gateway
